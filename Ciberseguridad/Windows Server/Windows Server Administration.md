Database  that contains all the domain objects
- user accounts
- computer accounts
- groups
-etc

- Installing, configuring, and updating apps.
- Managing the security infrastructure.
- Enabling Remote Access Service and DirectAccess.
- Issuing and managing digital certificates. ^N8EB4eMb

Partition               Portion of the AD DS that contains different info.

Schema                 The set of definitions of the object types and attributes.

Domain                 Logical container for objects and can be organize with parent-child relationships.

Domain tree           Hierarchical cluster of domains with root domain and same Domain Name System (DNS).

Forest                 Collection of 1 or more domains, common AD DS root, schema and global catalog.

OU                     Container object for users. groups and computers, we can delegate admin rights using Group Policy Objects (GPOs).

Container              Object with organizational framework, you can't link GPOs to containers.
