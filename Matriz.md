
| **Categoría**               | **Aspecto**                   | **Palo Alto Networks (Precision AI)**                                                                             | **Trend Micro (Full-Stack AI Protection)**                                                                    |
| --------------------------- | ----------------------------- | ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **Estrategia**              | **Enfoque declarado**         | **Secure AI by Design:** La seguridad como acelerador. Protege desde agentes autónomos hasta modelos.             | **Full-Stack AI Protection:** Innovación con supervisión. Énfasis en gestión de exposición y cumplimiento.    |
|                             | **Agrupación de capacidades** | Plataforma Prisma (SASE + AIRS 2.0 + Navegador) + NGFW.                                                           | Plataforma Trend Vision One + Zero Trust Secure Access (ZTSA) + AI Security Blueprint.                        |
| **Visibilidad**             | **Qué detecta**               | Agentes de IA autorizados y no autorizados (Shadow AI).                                                           | Modelos de IA en uso, su configuración y exposición.                                                          |
|                             | **Metodología**               | Inventario automático vía Prisma AIRS 2.0 y telemetría de red/endpoint desde Prisma SASE.                         | Análisis de exposición centralizado en Vision One con el módulo "AI Service Access".                          |
|                             | **Identificación**            | Por usuario y herramienta específica (ChatGPT, Copilot, etc.).                                                    | Con contexto de identidad y estado del dispositivo.                                                           |
|                             | **Diferenciador**             | Detecta agentes de IA autónomos, no solo aplicaciones web.                                                        | Enfoque en riesgos de configuración y permisos de modelos.                                                    |
| **Control**                 | **Granularidad**              | Por app, usuario, rol, contexto y acción (ej. bloquear copiar/pegar o subir archivos).                            | Por app, identidad, dispositivo y nivel de riesgo dinámico.                                                   |
|                             | **Mecanismo**                 | Políticas en Prisma SASE + control nativo en Prisma Access Browser.                                               | Políticas dinámicas en Zero Trust Secure Access (ZTSA).                                                       |
|                             | **Diferenciador**             | Control hasta el nivel de interacción dentro del navegador.                                                       | Evaluación continua de riesgo antes de cada acceso al servicio.                                               |
| **DLP para IA**             | **Prevención**                | En prompts y cargas de archivos (uploads).                                                                        | En prompts y respuestas generadas por la IA.                                                                  |
|                             | **Tecnología**                | Clasificación de datos sensibles mediante LLM integrado.                                                          | Inspección profunda de prompts y respuestas en servicios GenAI.                                               |
|                             | **Diferenciador**             | Bloqueo del pegado de datos sensibles en el navegador (última milla) antes de llegar a la red.                    | Auditoría completa (log) de todo lo enviado y recibido del servicio de IA.                                    |
| **Gobernanza**              | **Reportes GRC**              | "Listado de ingredientes" del modelo (arquitectura, datasets, licencias).                                         | Risk Insights y tableros de cumplimiento normativo.                                                           |
|                             | **Diferenciador**             | Enfoque en transparencia técnica para auditores de seguridad.                                                     | Enfoque en cumplimiento y gestión de exposición para auditores legales.                                       |
| **Tiempo Real**             | **Defensa Ofensiva**          | Red Team autónomo con +500 tipos de ataques contra modelos propios.                                               | AI Scanner para detectar vulnerabilidades en modelos y guardarraíles inteligentes.                            |
|                             | **Diferenciador**             | Capacidad de probar ofensivamente los modelos internos de la empresa.                                             | Guardarraíles aplicables a servicios de terceros (ChatGPT, etc.).                                             |
| **Arquitectura**            | **Capa de Red**               | Firewall (NGFW) y Prisma SASE como puntos de inspección.                                                          | ZTSA como controlador de acceso principal.                                                                    |
|                             | **Capa Browser**              | Navegador corporativo nativo (Prisma Access Browser) con controles incrustados.                                   | No tiene navegador propio; depende del agente o ZTNA.                                                         |
| **Análisis de Información** | **Presencia en Internet**     | **Muy Alta.** Amplia base de conocimientos técnica, whitepapers de "Platformization" y casos de uso de XSIAM.     | **Muy Alta.** Enfoque fuerte en blogs de investigación de amenazas (Trend Micro Research) y guías operativas. |
|                             | **Novedad de Documentación**  | **Extrema.** La mayoría de la info sobre Prisma AIRS 2.0 y Precision AI es de finales de 2025/principios de 2026. | **Alta.** Documentación constante sobre su AI Security Blueprint y la integración de Trend Companion.         |
|                             | **Público Objetivo**          | Equipos de seguridad técnica y arquitectos de red que buscan consolidación total.                                 | Equipos de gestión de riesgo, cumplimiento y SOC que buscan respuesta asistida.                               |
